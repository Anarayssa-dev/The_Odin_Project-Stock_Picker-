# The_Odin_Project
O Projeto Odin fornece um currículo gratuito de codificação de código aberto que pode ser tomado inteiramente online. Desde a sua criação, ajudou muitos estudantes a serem contratados como desenvolvedores e ajudou inúmeros outros em aprender programação suficiente para trabalhar em seus próprios projetos pessoais. 
Acesso: [https://www.theodinproject.com](https://www.theodinproject.com)
### Project: Stock Picker

Objective: ***Implement a method that takes a word as the first argument and then an array of valid substrings (your dictionary) as the second argument. It should return a hash listing each substring (case insensitive) that was found in the original string and how many times it was found.***

Example:

~~~ruby
   > stock_picker([17,3,6,9,15,8,6,1,10])
  => [1,4]  # for a profit of $15 - $3 == $12
~~~
